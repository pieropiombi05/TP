# TP

Este repositorio contiene dos carpetas:

- **[`womboo-next/`](womboo-next/)** — Es el proyecto y la entrega principal: la tienda de Womboo construida con Next.js (catálogo, carrito, checkout con MercadoPago, panel de administración). Ver [`womboo-next/README.md`](womboo-next/README.md) para instrucciones de instalación, variables de entorno y despliegue.
- **`womboo/`** — Versión estática previa del sitio (HTML/CSS/JS plano). Queda como histórico de referencia y **no** es la entrega.
